🎯 Problem Statement

Police departments often rely on manual records and fragmented datasets, making it difficult to identify crime patterns, hotspot regions and future risks. This project transforms historical crime records into meaningful insights through interactive dashboards and Machine Learning based forecasting.

🚀 Key Features

✔ Crime Trend Analysis

✔ District-wise Crime Hotspot Identification

✔ Interactive Power BI Dashboards

✔ Karnataka Shape Map Visualization

✔ Crime Severity Analysis

✔ Machine Learning Forecasting (2025–2030)

✔ Decision Support for Law Enforcement

🗄 MySQL – Data Storage & Querying

📈 Power BI – Interactive Dashboard Development

🐍 Python – Machine Learning & Forecasting
