Welcome

The KSP Crime Intelligence Platform is an analytical solution developed for the Karnataka State Police Datathon 2026. It transforms traditional crime records into meaningful insights through interactive dashboards, crime hotspot identification and machine learning based forecasting.

✨ Key Features

✔ Crime Trend Analysis

✔ District Hotspot Identification

✔ Interactive Power BI Dashboards

✔ Machine Learning Crime Forecast (2025–2030)

✔ Data Driven Decision Support for Law Enforcement
